# running-coach
Linking strava and Claude to help me to run a marathon.

## Two ways to use it

- **Claude Code / Claude Desktop skill** (`SKILL.md`, `scripts/`): runs the Python scripts on your computer. Setup is in [SETUP.md](SETUP.md).
- **Connector for claude.ai and the Claude mobile apps** (`mcp-server/`): a small server on Cloudflare's free plan that Claude connects to over the internet. Setup is in [mcp-server/README.md](mcp-server/README.md).
